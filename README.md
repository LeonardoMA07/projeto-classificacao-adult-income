# Classificação da Faixa de Renda de Adultos

Etapa 1 do projeto de Machine Learning: análise exploratória (EDA) e pré-processamento do dataset [Adult Income Census](https://www.kaggle.com/datasets/anaghakp/adult-income-census).

**Site do projeto:** https://leonardoma07.github.io/projeto-classificacao-adult-income/

**Notebook:** [docs/projeto_adult_income_eda.ipynb](docs/projeto_adult_income_eda.ipynb)

## Rodar o notebook

```bash
pip install -r requirements.txt
jupyter notebook docs/projeto_adult_income_eda.ipynb
```

## Atualizar o site

```bash
mkdocs serve       # pré-visualiza em http://127.0.0.1:8000
mkdocs gh-deploy   # publica no GitHub Pages
```
